### 🌊 The Framework

The core of the Riptide ecosystem is a performance-first architecture designed to solve the most painful scaling issues in Roblox development.

*   **[Riptide Framework](https://github.com/riptide-project/framework)**: Modular lifecycle, unified networking, and sandboxed plugins built with 100% strict Luau.

---

### ⚡ Core Philosophy

1.  **Strict Typing**: Industry-grade Luau with 100% `--!strict` coverage.
2.  **Deterministic Logic**: Eliminating race conditions through phased initialization.
3.  **Modular Power**: A lean core with a powerful, sandboxed plugin system.
4.  **Performance First**: Zero-allocation primitives and optimized networking.
