## Why Riptide?

Riptide is designed for Roblox teams that need speed **and** long-term maintainability.  
It provides a clean architectural core today, and a scalable ecosystem for tomorrow.

- **Production-first architecture**: deterministic lifecycle, strong module boundaries, predictable behavior.
- **Strict developer experience**: typed APIs, clear patterns, and less architectural drift as teams grow.
- **Unified networking and state approach**: practical primitives for real multiplayer game workloads.
- **Composable ecosystem direction**: keep the Framework core lean, then extend through official add-ons.

## Plugin System Vision

Riptide is evolving toward an official **plugin system** for the Framework.  
Plugins are intended to work as **add-ons**: optional, focused, and tightly integrated without bloating the core.

**Data is the first plugin in this model.**
